    Hydra Arena

    An AI builds an app.
    Chaos breaks it.
    Kane has to catch it.

    Every run below is a real recording. A coding agent ships a checkout app, Hydra secretly plants one bug, and Kane CLI tests it in a real browser. If Kane catches the bug, the agent has to fix it using only Kane's evidence, and the fix only ships if fresh Kane runs and a hidden test pass. Some builders try to cheat.

    1. 1Build. An agent builds the app. Kane checks it twice while it is still clean.
    2. 2Break. Hydra hides one bug in the code. Nobody is told which.
    3. 3Catch. Kane runs its test in a browser and reports what it saw.
    4. 4Heal. The agent gets only Kane's report and must fix the app. A gate checks it didn't cheat.

              What am I looking at?
              
      
    
              
    
              Hydra tests whether a coding agent can fix a bug it never sees. A chaos step hides one bug in the app, Kane CLI checks the app in a real browser, and the agent only gets Kane's evidence. Each page is one run, read like a match report.
              
    
              
      
              Builder
              The coding agent under test. It writes and patches the app.
              
      
              Chaos
              The step that hides one bug in the builder's code. The builder is not told what or where.
              
      
              Kane
              The referee: a CLI that runs the app in a real browser against a plain-English spec and returns PASS (exit 0) or FAIL (exit 1).
              
      
              Baseline
              Two Kane runs before the bug goes in, to prove the specs pass on clean code. If they don't, the run doesn't count.
              
      
              Heal
              The builder gets Kane's failure evidence as its only prompt and patches the code.
              
      
              Verify
              Kane runs again after a patch. Two fresh passes are needed.
              
      
              Holdout
              A second checkout the builder never sees (other coupon, other quantities). It catches fixes fitted to the visible spec.
              
      
              Oracle, ground truth
              Scripted checks that know the real answer. They score Kane's verdicts. They never gate a deploy.
              
      
              False green
              Kane said PASS while the oracle said FAIL.
              
      
              Deploy gate
              The last check: two fresh passes, the holdout passed, specs unchanged, source unchanged since verify. It has no override.
              
      
              Spec tamper
              The builder changed a Kane spec file. The gate rejects the round and restores the spec.
              
      
              Miss
              Kane passed while the bug was present. Hydra logs it instead of hiding it.
              
      
              Kane credits
              Kane's usage cost for a run, as reported by kane-cli.
              
      
              ShareLink
              A link to the run in Kane's dashboard. It expires, so the evidence is also archived here.
