Hydra knows exactly which bug it planted, so it can score both sides: the coding agents that have to fix the app, and Kane CLI, which has to catch the bug. Every number here comes from a recorded run you can replay.

Coding agents

Each agent gets only Kane's evidence: what Kane saw, the failing step and screenshots. Never the diff, never the bug's name. A fix ships only after two fresh Kane passes and a hidden holdout test the agent never saw.

Kane's catch map

How Hydra closes the gaps

  • Hidden holdout. A second Kane flow with a different coupon and quantity. It caught the hardcoder, whose fix passed the visible test twice.
  • Misses are logged, never hidden. A miss is an outcome in the ledger, with the oracle's proof that the bug was there.
  • Spec agent. After a miss, an agent can write a new Kane flow aimed at the part of the app the old one never touched.
